# agro-llm-prompt-engineering
# Разработка и оптимизация системных промптов для LLM-ассистентов в АПК

Курсовой проект (ФГБОУ ВО «КубГУ», ФКТиПМ, Центр искусственного интеллекта).

## Цель проекта
Разработка, итеративная оптимизация и тестирование системы промптов для больших языковых моделей (LLM) в задаче первичной диагностики проблем сельскохозяйственных культур и состояния почвы по текстовым описаниям фермеров Краснодарского края.

## Задачи и план работ
- [x] Инициализация репозитория и постановка задачи
- [ ] Сбор тестового датасета (25–30 типовых агрономических кейсов с эталонными разборами)
- [ ] Разработка скрипта автоматического бенчмаркинга через API (Python)
- [ ] Итерация 1: Baseline-промпт (Zero-shot) и фиксация ошибок
- [ ] Итерация 2: Системный промпт с ролью, ограничениями безопасности и строгим JSON-выводом
- [ ] Итерация 3: Оптимизация с помощью Few-shot и Chain-of-Thought
- [ ] Исследование влияния параметров генерации (`temperature`, `top_p`) и сравнение моделей
- [ ] Сводный анализ метрик и оформление отчета

## Структура репозитория
- `data/` — датасет агрономических кейсов и эталонные ответы
- `prompts/` — версии системных промптов (`v1`, `v2`, `v3`)
- `src/` — Python-скрипты для запуска моделей и подсчета метрик
- `results/` — логи генераций, таблицы сравнения и графики
