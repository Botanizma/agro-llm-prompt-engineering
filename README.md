## Цель проекта

Разработка, итеративная оптимизация и экспериментальная оценка системы системных промптов и параметров генерации (`temperature`, `top_p`) для открытых больших языковых моделей (LLM) в задаче первичной диагностики проблем сельскохозяйственных культур и состояния почвы по текстовым обращениям фермеров Краснодарского края.

## Быстрый запуск локально

1. Установить [Ollama](https://ollama.com/) и загрузить исследуемые модели:
   ```powershell
   ollama pull qwen2.5:7b
   ollama pull deepseek-r1:7b
   ```
2. Установить зависимости Python:
   ```powershell
   pip install openai matplotlib
   ```
3. Запустить прогон базового промпта (`v1`):
   ```powershell
   python src/run_eval.py --prompt prompts/v1_baseline.txt --version v1 --temp 0.1
   ```
