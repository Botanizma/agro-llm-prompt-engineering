# Разработка и оптимизация системных промптов для LLM-ассистентов в АПК

Курсовой проект по направлению 01.03.02 «Прикладная математика и информатика» (ФГБОУ ВО «КубГУ», ФКТиПМ, Центр искусственного интеллекта).

- **Исполнитель:** Джанинян Роман Юрьевич
- **Научный руководитель:** д-р техн. наук, проф. Бухановский А.В.
- **Исследуемые модели:** Qwen 2.5, DeepSeek-V3
- **Сроки реализации:** 01.10.2026 - 05.12.2026

## Цель проекта
Разработка, итеративная оптимизация и экспериментальная оценка системы промптов и параметров генерации для больших языковых моделей (LLM) в задаче первичной диагностики проблем сельскохозяйственных культур и состояния почвы по текстовым описаниям фермеров Краснодарского края.

## Планируемая структура репозитория
- `data/` - тестовый датасет агрономических кейсов с эталонными разборами
- `prompts/` - эволюция системных промптов (`v1`, `v2`, `v3`)
- `src/` - Python-скрипты для прогона моделей через API и подсчета метрик
- `results/` - сырые логи ответов моделей, таблицы сравнения и графики
